# SEOコンテンツ戦略スタジオ

Serper APIとGemini APIを利用し、Google上位10サイトの競合リサーチからSEO記事、SNS投稿文、画像・動画制作用プロンプトまで生成するStreamlitアプリです。画像・動画そのものは生成しません。

## 4つのタブ

### 競合分析→一括制作

検索キーワードから上位10サイトのH2・H3、推定文字数を取得し、必須トピック、検索意図の隙間、差別化ポジション、制作方針を分析します。その結果を引き継いで、次の順に制作できます。

1. 競合分析
2. 検索意図・記事構成・本文
3. WordPress貼り付け用HTML
4. SNS投稿文
5. SNS画像・動画制作用プロンプト

記事とSNSは別ボタンで生成するため、Gemini無料枠を必要な分だけ使えます。記事生成が途中で止まった場合は、完成済みの見出しを保持して途中から再開できます。

### キーワードからSEO記事

検索意図分析、H2・H3構成、H2単位のPREP法による本文執筆を順番に行います。体験談・独自ノウハウのメモ、途中再開、WordPress用HTMLに対応しています。

### URLから紹介記事

指定ページを読み込み、検索意図分析、構成作成、H2単位の本文執筆を行います。対象ページで確認できない数値・実績・口コミなどを作らないよう制限しています。

### 記事からSNS展開

完成記事または貼り付けた記事から、次の内容を生成します。

記事は直接貼り付けるほか、アプリからダウンロードした `seo_article.md` をそのままアップロードできます。`.md`、`.txt`、`.html`、`.htm` に対応し、`seo_article.md` 内の「完成した本文」だけを自動抽出します。

- X投稿文3パターン
- Facebook投稿文
- Googleビジネスプロフィール投稿文
- Threads投稿文
- Instagramカルーセル9枚の構成とキャプション
- Instagramリール、YouTube、TikTokの動画台本
- X、Facebook、GBP、Threads、リール表紙、YouTubeサムネイル、TikTok表紙の画像制作プロンプト
- Instagramカルーセル9枚それぞれの画像制作プロンプト
- Instagramリール、YouTube、TikTokの動画制作プロンプト
- 完成記事のH2・H3ごとの記事内画像制作プロンプト

制作プロンプトは、1件だけコピーしても成立する完成形です。画像ではイラスト領域とテキスト領域を完全分離し、プロのイラストレーター品質、人物・表情・背景・小物・光・配色・構図、日本語フォント、文字サイズ、自然な改行、安全余白、禁止事項まで指定します。

画像・カルーセル・動画は、完成記事を「悩み・重要ポイント・具体策・注意点・まとめ」へ整理してから制作します。各スライド・各シーンへ記事内容に合う人物、表情、動作、背景、小物を個別指定し、同じ構図の使い回しを避けます。明るい自然光、透明感のあるパステルカラー、鮮やかなアクセントカラーを基本とし、暗い・くすんだ・重苦しい表現を避けます。

Instagramカルーセルは、9枚だけを順番に読むことで記事の主要内容を理解できる要約構成です。生成した9枚を01〜09の順に動画の絵コンテとして再利用し、約55〜60秒のリール・YouTube・TikTok用動画プロンプトを作成します。動画はカルーセルと別内容にせず、各画像へ緩やかなズーム、パン、光、自然な微動とタイピング表示を加えます。

動画プロンプトには、読みやすい長さの表紙、上下テキストの重複禁止、自然な日本語改行、音声ナレーションを使わないタイピング表示、明るくポップなインストBGM、映像とテロップの同期、最後の行動案内を含めます。SNS名・ロゴ・ユーザー名・保存ファイル名・透かしは動画内へ表示しません。

## APIキー

競合検索にはSerper APIキー、分析・記事・SNS制作にはGemini APIキーを使います。画像・動画生成APIキーは使用しません。

1. [Google AI Studio](https://aistudio.google.com/apikey)を開きます。
2. APIキーを作成してコピーします。
3. Gemini APIキーとSerper APIキーをStreamlit Community Cloudの **Settings → Secrets** に登録します。

毎回の入力を省く場合は、Streamlit Community Cloudの **Settings → Secrets** に次を登録します。

```toml
GEMINI_API_KEY = "実際のGemini APIキー"
GEMINI_MODEL = "gemini-3.5-flash-lite"
SERPER_API_KEY = "実際のSerper APIキー"
```

登録後は、アプリ画面でAPIキーを毎回入力する必要はありません。

## 注意事項

- 画像・動画は生成せず、制作プロンプトだけを作成します。
- アクセス制限、JavaScript描画、robots設定などにより、一部ページの見出しを取得できない場合があります。取得不能ページの内容は推測しません。
- 出力されたプロンプトを、お使いの画像生成AI・動画生成AIへ貼り付けて使用してください。
- 画像・動画生成サービスによって、日本語文字や音声への対応状況が異なります。
- AI生成文と制作物は公開前に、事実、誤字、文字化け、不自然な改行、医療表現を確認してください。
- 氏名、住所、症例などの個人情報は入力しないでください。
- 有料請求を設定しない限り、このアプリから自動的に有料枠へ切り替わることはありません。

# 記事リライトの追加（2026-10-06）

更新時は `app.py` を置き換え、`rewrite_tools.py` を同じ階層に追加してください。ZIP内の他のファイルも含めて更新できます。APIキーは既存のGemini設定を利用し、リライトだけならSerperは不要です。

1. 「記事リライト」タブを開きます。
2. 「記事を貼り付ける」か「URLから読み込む」を選びます。
3. URLの場合は「URLから本文を読み込む」を押し、取得した本文を確認・修正します。閲覧制限やJavaScript表示などで取得できない場合は本文を貼り付けてください。
4. 対策キーワード、想定読者、目的、変更指示を必要に応じて指定し、「記事をリライトする」を押します。
5. 完成記事、変更点、公開前の確認事項、メタディスクリプションを確認します。記事は編集でき、Markdown・WordPress用HTMLで保存できます。
6. 「記事からSNS展開」で「リライトした完成本文」を選ぶと、編集後の記事からSNS投稿文・画像動画プロンプトを作成できます。

元記事は100〜30,000文字、完成本文は最大8,000文字程度が目安です。AIには原文の事実・固有名詞・料金・条件を保持するよう指示しますが、公開前に必ず照合してください。検索順位の保証や事実の外部検証は行いません。公開中の元ページを自動更新する機能ではありません。
結果は同一セッション内で保持されます。ページの再読み込みやサーバー再起動に備え、完成記事をダウンロードしてください。既存のSNS・カルーセル・動画・文字なし記事内イラストの制作基準は継続します。

## URL接続エラー対応（2026-10-14）

- 接続と読み取りの待ち時間をそれぞれ30秒に設定。接続失敗・タイムアウトやHTTP 502/503/504では2秒待って1回再試行します。
- SSL検証と公開URL・リダイレクト先の検証は維持します。サイト側の接続制限は解除しません。
- 「URLから紹介記事」のURL欄の下に「ページ本文を貼り付ける」欄を追加しました。Safariでコピーした本文を100〜30,000文字で入力して「紹介記事を生成する」を押してください。本文がある場合はURLへ接続せず、貼り付け内容を使います。URLは任意です。
- 通信・HTTPエラーを日本語で案内します。読み込み失敗時に前回の記事を消さないようにしました。
- URLからのリライトにも接続の再試行が適用されます。取得できない場合は「記事を貼り付ける」を利用してください。

GitHubの **app.py** を今回のファイルに置き換えてください。リライト機能が未導入の場合は、ZIP内の rewrite_tools.py などのPythonファイルと requirements.txt も同じ階層へアップロードしてください。ZIPをそのままアップロードするのではなく、解凍した中身を更新します。公開アプリへの反映後、「ページ本文を貼り付ける」欄が表示されることを確認してください。

## 接続診断・IPv4接続の追加（2026-10-15）

更新するファイル：app.py、connection_tools.py（新規）、packages.txt。3ファイルを同じ階層へアップロードしてください。packages.txtにcurlを追加しています。Streamlit側の環境構築が終わってから操作してください。

「URLから紹介記事」タブでURLを入力し、「URLを読み込めない場合：接続診断・接続方法」を開いて「このURLの接続を診断する」を押します。実際にアプリが動いている環境でDNS・IPv4/IPv6ごとのTCP接続・TLS証明書確認を行います。各方式の最初の接続先だけを検査します。IPv6接続先がないこと自体は異常ではありません。HTTP本文の取得や制限の有無を保証する診断ではありません。

IPv4が成功してIPv6が失敗する場合は「IPv4で接続する」を選んで、通常通り「紹介記事を生成する」を押します。この接続方式はURL紹介記事で利用できます。サーバー全体の通信設定は変更しません。サイト側の制限を解除する機能ではなく、成功は保証されません。

両方のTCP接続に失敗する場合は、診断結果を保存して管理会社へ確認できます。本文貼り付けを使えば、URLへの接続なしで生成できます。APIキーは診断結果に含みません。
